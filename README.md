# CampusFind 🎒

A simple Lost and Found website made for college students.

We've all experienced losing something on campus or finding an item that belongs to someone else. CampusFind aims to make this process easier by providing one place where students can report lost and found items.

### What can you do?
- Report an item as Lost or Found.
- Add its name, description and contact details.
- View items reported by other students.
- Check whether an item is Lost or Found.

### Built using
- HTML and CSS
- PHP
- MySQL
- XAMPP

### Running the project locally
1. Install XAMPP and start Apache and MySQL.
2. Place the project folder inside `htdocs`.
3. Create a database called `campus_lost_found`.
4. Create the required `items` table.
5. Configure your local database connection in `db.php`.
6. Visit `http://localhost/campus_lost_found/`.

### About
This is a college mini-project built to practise frontend development, PHP and database connectivity.
